## 2. ПРОСМОТР ПИСЬМА (графическое представление в Figma)

![Просмотр письма](/docs/ui_prosmotr.png)
Верхняя панель (кнопки):

- Назад
- [Ответить]

✉️ Описание письма:

- От: teacher@school.ru
- Кому: student@college.ru
- Тема: Задание на практику
- Дата: 20 мая 2024, 10:00

- Текст письма:
- Уважаемый студент! Нужно разработать почтовый клиент с основными функциями..
  С уважением, Преподаватель ...

  Нижняя панель (кнопки):

- [Удалить]
- [В черновики]
- [Переслать]
